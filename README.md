# Котики-догонялки

Маленькая игра на TypeScript + Vite. Чиби-котики бегут за курсором (клубочком),
плюхаются рядом и тетешкаются, а когда курсор уходит, встают и бегут снова.

Правила: игра начинается с пяти котиков. На поле появляются угощения, за каждое
съеденное прибегает ещё один котик. На каждое угощение с края прибегает собачка и
пытается забрать его первой. Если котики несколько секунд ничего не едят (таймер
настраивается на стартовом экране), они по одному разбегаются. Когда котиков не
остаётся, игра заканчивается и показывает итоги.

## Запуск

```bash
npm install
npm run dev      # dev-сервер с hot reload
npm run build    # проверка типов + сборка в dist/
npm run preview  # посмотреть собранную версию
```

## Как устроено

- `src/critter.ts` — базовый класс `Critter`: спрайт на сцене, рулёжка к точке, отрисовка.
- `src/cat.ts` — `Cat`: SVG-котик, стейт-машина `running → tumbling → cuddling → rising`,
  своё «место» рядом с курсором, три характера по скорости, детур за угощением.
- `src/dog.ts` — `Dog`: прибегает с края на каждое угощение, три характера по скорости, уносит добычу в зубах.
- `src/items.ts` — угощения (рыбка, мышка, печенька) и их SVG.
- `src/game.ts` — `Game`: фазы меню/игра/итоги, спавн угощений и собачек, подбор при
  наступании, прирост котиков за еду, таймер голода, статистика.
- `src/main.ts` — курсор-клубочек, экраны (меню, HUD, итоги), настройки в localStorage,
  игровой цикл на `requestAnimationFrame`.
- `src/style.css` — темы (светлая/тёмная), панель, все анимации в keyframes.
